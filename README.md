\# Police HQ Management System



A full-stack Police Headquarters Management System designed for managing police officers, departments, attendance, reports, police stations, transfers, promotions and administrative operations.



\## Live Application



Frontend:

https://police-hq-management-system.vercel.app



Backend API:

https://police-hq-management-backend.onrender.com



Health Check:

https://police-hq-management-backend.onrender.com/api/health



\## Repository



GitHub:

https://github.com/nirdosh919/Police-HQ-Management-System



\## Features



\- Secure Administrator Login

\- Officer Management

\- Officer Profiles

\- Officer Photograph \& Document Upload

\- Department Management

\- Police Station Management

\- Attendance Management

\- Reports \& Analytics

\- Transfers \& Promotions

\- Headquarters Management

\- Audit Logs

\- Dashboard Overview

\- Authentication \& Authorization

\- JWT Based Authentication

\- MongoDB Database

\- Responsive Government Portal Style UI
